# Automech

A mechanic marketplace connecting drivers with repair services, live across six countries.

**This repository documents my contribution. The source belongs to the company and is not published here.**

### What it is

Automech lets drivers find and book mechanics, and gives mechanics a dashboard to manage incoming work. It operates in Cyprus, Greece, Estonia, Latvia, Lithuania and Germany.

- **Google Play** — [app.automateonline.user](https://play.google.com/store/apps/details?id=app.automateonline.user)
- **Site** — [automateonline.app](https://automateonline.app)

### My role

**Frontend and UI/UX.** I designed and deployed the responsive product site, and delivered the interface design for both the consumer-facing and mechanic-facing applications.

I did not work on the backend, and this was a team project — the platform is not solely my work.

### How it's built

React · Next.js · Tailwind CSS · responsive layouts across mobile and desktop

### Notes

The interesting constraint was designing one interface that works for two very different users. A driver needs to describe a problem they may not have the vocabulary for and see a price they can trust; a mechanic needs to triage a queue of incoming jobs quickly. Serving both without building two separate products shaped most of the design decisions.
